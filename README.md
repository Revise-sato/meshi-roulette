# メシ決めルーレット

**今日のメシ、決めます。** 迷ってる時間がいちばんもったいないので。

👉 **https://revise-sato.github.io/meshi-roulette/**

## 使い方

| モード | 引くもの | そのあと |
|---|---|---|
| **近くから決める** | ジャンル17種から1つ | Google マップで**現在地のまわり**をそのジャンルで検索 |
| **チェーンから決める** | チェーン114軒から1軒 | Google マップでその店を現在地のまわりで検索 |

- 条件でしぼれる：ジャンル／予算の目安／気分（ひとりで入りやすい・すぐ出てくる・がっつり・野菜がとれる…）
- 気に入らないチェーンは「しばらく出さない」で候補から外せる（同じボタンで戻る）
- 直近に出たものはしばらく出ない
- **iPhone**：Safariで開いて 共有 →「ホーム画面に追加」。アイコンが並んで、アプリのように開けます
- **Android**：Chromeのメニュー →「アプリをインストール」

## つくりの話

- **HTML 1枚**。サーバーもアカウントもログインも無し
- **位置情報をこのアプリは受け取りません。** 現在地を使うのは飛んだ先のGoogleマップだけ
- 条件・除外・履歴は**その端末のブラウザの中だけ**に残ります。どこにも送りません
  （唯一の外部通信は、文字の見た目のために Google Fonts を読むところだけ。あなたのデータは載りません）
- 一度開けば**オフラインでも抽選は動きます**（Service Worker）

## 注意

チェーンの予算帯とタグは**ざっくりした主観**です。実際の値段・営業時間・その街に店があるかは保証しません。
店が見つかるかどうかは Google マップ側の結果しだいです。

## 直すとき

このフォルダは生成物です。実体は別リポジトリにあり、`build.py` が `index.html` / `sw.js` / `manifest.webmanifest` を組み立てています。
チェーンの追加・削除は元の `CHAINS` 配列（`{n:名前, g:ジャンル, p:予算1-3, t:[タグ]}`）を触ります。
